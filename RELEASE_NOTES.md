## 📋 Release Notes - Mistus Copy Pasta (v1.3.28)

### 🖱️ Mouse-Hold Flexible Drag-and-Drop Reordering
- **Desktop Floating Pill Bar**:
  - Simply **hold and drag any pinned chip** with your mouse to move it around and drop it into any other position!
  - Real-time semi-transparent drag ghost and emerald drop highlight indicate the exact drop target.
  - Seamlessly complements existing 1-click context menu Move Left / Move Right options.
- **Main Detailed Window**:
  - Each pinned clipping card now has a dedicated **drag handle grip button (`⠿`)** in addition to the Up (`↑`) and Down (`↓`) buttons.
  - Hold and drag any pinned card onto another pinned card to instantly swap slots, or drop directly into any empty slot (`Slot #1`..`#20`) to reserve that specific position.
  - Visual dashed drag borders provide clear, smooth drop feedback.
