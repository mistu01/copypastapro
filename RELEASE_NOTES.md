## 📋 Release Notes - Mistus Copy Pasta (v1.3.29)

### 📁 Screenshot & Media Storage Locations
- **Default Screenshot Save Location Set to Desktop**:
  - The Save dialog (`Ctrl + S` or Save button in the screen capture overlay) now opens directly to the user's **Desktop** by default (`C:\Users\<User>\Desktop`).
  - Allows immediate access to saved captures without drilling through nested folders.
- **Dedicated User Media Folder in Pictures**:
  - All captured and copied clipboard screenshots and media thumbnails are now cleanly stored in the user's **Pictures** folder under `Pictures\CopyPasta` (with fallback to `Documents\CopyPasta`).
  - Zero files are stored within the Program Files installation directory or restricted folders.
